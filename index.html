书籍信息服务 · 配置指南

为扫码录入，
多添一个信息来源。

万维易源提供 ISBN 图书查询服务，可按 ISBN 获取书名、作者、出版社等书目信息。 申请自己的 API Key（平台称为 appKey），即可在“我的书架”中配置并启用。

打开万维易源服务页面 ↗ （在新标签页打开）
  1. 01

    注册并获取 appKey

    打开上方服务页面，注册或登录万维易源。点击“查看我的 appKey”或“查看密钥”， 进入控制台获取并复制自己的 appKey。

  2. 02

    在应用中填入并启用

    进入“我的 → 书籍信息服务”，找到“万维易源”，将 appKey 粘贴到 “万维易源 appKey”输入框，并确认该服务的启用开关已打开。

  3. 03

    测试连接，然后保存

    点击“测试 Key”检查连接。测试成功后，点击页面右上角“保存”， 即可在扫码或输入 ISBN 时使用。仅测试不会保存配置。

调用额度与服务规则以万维易源官方页面为准。“测试 Key”会实际发起一次查询，可能消耗服务调用额度。

开始之前

你可能想知道

关于这座小小的私人藏书馆。

这是一款电子书阅读器吗？

我的书架主要用于管理个人藏书：记录书目信息、阅读状态与存放位置。它不提供电子书正文，也不提供书籍文件下载。

没有 ISBN，或者查不到书籍怎么办？

可以手动添加书名、作者等信息，不必填写 ISBN。在线查询依赖第三方书目来源，信息可能不完整，你可以在保存前核对，也可以之后继续编辑和补全。

可以离线使用吗？

已保存书目的查看、搜索、分类与整理可以离线进行。在线书目查询、网络封面的获取需要网络；部分书目服务需在应用中配置自己的 API Key。网络封面不等同于已保存在本机的图片。

换手机时，怎样带走我的书架？

在“我的 → 数据导入导出”中导出完整 ZIP 备份，将文件保存到其他位置，在新设备安装应用后再恢复。完整备份包含本地图片与设置；CSV 更适合表格交换。建议定期备份，并在恢复前核对预览。
